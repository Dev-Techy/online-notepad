Deployment & Setup

This web app is 100% self-contained and ready to host anywhere!

Deployment Steps (Vercel/Netlify):

1. Put this `index.html` in a folder or Git repo.

2. Drag-and-drop or push to Vercel / Netlify / GitHub Pages.

3. Open your generated web link on any phone or PC!

Note: Built with Firebase Firestore logic. Automatically syncs edits across devices accessing the same room ID link.
