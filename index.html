Deployment Guide

This web application is completely self-contained in a single file!

To deploy on Vercel or Netlify:

1. Name this file index.html.

2. Push to GitHub or drag-and-drop into Netlify/Vercel.

3. Access your link on any Wi-Fi or phone!

Note: Make sure Firestore security rules are enabled for read/write if using your own project credentials.
